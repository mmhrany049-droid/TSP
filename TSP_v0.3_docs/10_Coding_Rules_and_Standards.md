# قوانین کدنویسی و استانداردها برای هوش مصنوعی کدساز

این قوانین برای تمام کدهای Backend و Frontend نسخه ۰.۳ الزامی است.

---

## قوانین عمومی

1. کد باید تمیز، خوانا و خودتوضیح باشد.
2. از نام‌گذاری واضح و انگلیسی برای متغیرها، توابع و کلاس‌ها استفاده کن.
3. تمام متن‌های نمایش‌داده‌شده به کاربر باید فارسی باشد.
4. پیام‌های خطا فارسی و امن باشند.
5. هیچ متن سؤال تستی در دیتابیس ذخیره نشود.
6. هیچ تلاشی نباید overwrite شود.
7. ساختار کتاب و مبحث آموزشی همیشه جدا بمانند.

---

## قوانین Backend (Python)

1. از type hint در تمام توابع استفاده کن.
2. از SQLAlchemy 2.0 style (select, session.execute) استفاده کن.
3. تمام ورودی‌ها با Pydantic اعتبارسنجی شوند.
4. رمز عبور فقط به صورت هش ذخیره شود.
5. JWT دارای زمان انقضا باشد.
6. برای عملیات حساس از dependency injection استفاده کن.
7. docstring فارسی برای endpointها بنویس.
8. از چاپ sensetive data در لاگ خودداری کن.
9. خطاها را با HTTPException و پیام فارسی برگردان.
10. تنظیمات فقط از طریق متغیر محیطی خوانده شود.

---

## قوانین Frontend (TypeScript / Next.js)

1. تمام کامپوننت‌ها و توابع تایپ داشته باشند.
2. جهت صفحه `dir="rtl"` و `lang="fa"` باشد.
3. از فراخوانی مستقیم دیتابیس خودداری کن؛ فقط API.
4. حالت‌های loading، error و empty را همیشه مدیریت کن.
5. فرم‌ها اعتبارسنجی سمت کلاینت داشته باشند (علاوه بر سرور).
6. توکن را به روش امن مدیریت کن.
7. از any تا حد امکان استفاده نکن.
8. کامپوننت‌ها را کوچک و قابل استفاده مجدد نگه دار.
9. برای تاریخ‌ها آماده تبدیل به شمسی باش.
10. طراحی ساده، تمیز و کاربردی باشد (نه شلوغ).

---

## قوانین API

1. نسخه API در مسیر باشد (`/api/v1/...`).
2. کدهای وضعیت HTTP درست استفاده شوند.
3. ساختار خطای یکسان:
   ```json
   { "detail": "پیام فارسی" }
   ```
4. صفحه‌بندی برای لیست‌های بلند.
5. CORS فقط برای آدرس Frontend باز باشد.

---

## قوانین مدل داده

1. display_number هرگز unique نباشد.
2. QuestionAttempt فقط insert شود.
3. PreviousSolvedEntry جدول جدا باشد.
4. is_important و is_hard و publisher_difficulty سه فیلد جدا باشند.
5. حذف‌ها ترجیحاً نرم (is_active = false) باشند مگر خلافش صریح گفته شود.

---

## ممنوعیت‌ها

- استفاده از ORM دیگر غیر از SQLAlchemy در Backend
- ذخیره متن سؤال
- overwrite کردن سابقه حل
- مخلوط کردن BookNode و Topic
- نوشتن منطق کسب‌وکار در Frontend
- هاردکد کردن آدرس‌ها و رمزها
