## هدف این بسته

این پوشه شامل **تمام اسناد لازم** برای ساخت کامل نسخه ۰.۳ توسط هوش مصنوعی کدساز است.

نسخه ۰.۲ کنار گذاشته شده.  
نسخه ۰.۳ باید **تمام قابلیت‌ها** را داشته باشد (نه MVP ناقص).

### معماری نسخه ۰.۳

| لایه | تکنولوژی |
|------|----------|
| Backend | **Python** (FastAPI + SQLAlchemy + SQLite/PostgreSQL) |
| Frontend | **Node.js** (Next.js 15 + TypeScript + Tailwind) |
| احراز هویت | JWT (Backend) + مدیریت نشست در Frontend |
| پایگاه داده | SQLite برای شروع، قابل ارتقا به PostgreSQL |

## نحوه استفاده توسط هوش مصنوعی کدساز

1. ابتدا فایل‌های `01` تا `06` و `10` را کامل بخوان.
2. سپس طبق ترتیب فایل `09` عمل کن.
3. برای Backend از پرامپت‌های فایل `07` استفاده کن.
4. برای Frontend از پرامپت‌های فایل `08` استفاده کن.
5. هر پرامپت را جداگانه اجرا کن و خروجی را بررسی کن.

## اصول غیرقابل نقض نسخه ۰.۳

1. تاریخچه‌محور بودن کامل (هیچ تلاشی overwrite نمی‌شود)
2. جداسازی کامل ساختار کتاب (BookNode) از مباحث آموزشی (Topic)
3. شماره نمایشی تست یکتا نیست → شناسه داخلی اجباری است
4. تمام آمار از روی داده‌های خام محاسبه می‌شود
5. Backend و Frontend کاملاً جدا هستند و فقط از طریق API با هم حرف می‌زنند
6. رابط کاربری کاملاً فارسی و RTL است
7. تمام قابلیت‌های ذکرشده در نیازمندی‌ها باید پیاده شوند
