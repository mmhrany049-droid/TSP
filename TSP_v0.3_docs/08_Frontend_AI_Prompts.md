# پرامپت‌های ساخت Frontend (Next.js / Node.js)

قبل از هر پرامپت این متن را اضافه کن:

> تو یک توسعه‌دهنده ارشد Frontend با تخصص Next.js 15، TypeScript و Tailwind هستی. رابط کاربری باید کاملاً فارسی، راست‌به‌چپ (RTL) و زیبا باشد. از App Router استفاده کن. تمام متن‌ها فارسی باشند. کد تمیز و تایپ‌شده بنویس.

---

## پرامپت ۱: اسکلت Frontend

```
یک پروژه Next.js 15 با App Router + TypeScript + Tailwind CSS بساز.

نام پروژه: tsp-frontend

ساختار:
- app/(auth)/login و register
- app/(dashboard)/ با لایه‌بندی مناسب
- components/
- lib/api.ts (کلاینت API)
- lib/auth.ts
- types/
- پشتیبانی کامل RTL و زبان فارسی
- فونت فارسی مناسب (وزیرمتن یا مشابه)

متغیر محیطی:
NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1

هنوز صفحات را کامل پر نکن. فقط اسکلت + layout + تنظیمات RTL + کلاینت API پایه.
```

---

## پرامپت ۲: احراز هویت Frontend

```
صفحات و منطق احراز هویت را کامل پیاده کن.

- صفحه ثبت‌نام
- صفحه ورود
- ذخیره توکن (روش امن و ساده)
- ارسال خودکار هدر Authorization
- محافظت از مسیرهای داشبورد (اگر توکن نباشد به login هدایت شود)
- دکمه خروج
- نمایش نام کاربر

طراحی تمیز، مدرن و کاملاً فارسی باشد.
```

---

## پرامپت ۳: کتاب‌ها و ساختار

```
ماژول LibraryManager را در Frontend پیاده کن.

صفحات و قابلیت‌ها:
- لیست کتاب‌ها
- ایجاد کتاب جدید (فرم)
- صفحه جزئیات کتاب + نمایش درخت ساختار
- افزودن فصل و بخش به درخت
- ویرایش و آرشیو

UI باید برای ساختار درختی مناسب و قابل فهم باشد.
```

---

## پرامپت ۴: بانک تست و مباحث

```
صفحات مربوط به QuestionBank و TopicTree را بساز.

- لیست تست‌های یک کتاب / بخش
- فرم افزودن تست (شماره نمایشی + پاسخ صحیح)
- تیک مهم و سخت
- مدیریت درخت مباحث
- اتصال تست به مبحث

همه چیز فارسی و ساده باشد.
```

---

## پرامپت ۵: ثبت تلاش و مرور

```
ماژول AttemptTracker و SmartReview را در Frontend پیاده کن.

- صفحه حل تست (ورود پاسخ + زمان اختیاری)
- نمایش فوری نتیجه (درست/غلط)
- صفحه ورود تست‌های قبلاً حل‌شده
- صفحه مرور با فیلترهای:
  - غلط
  - نزده
  - مهم
  - سخت
  - ترکیب فیلترها
- علامت‌زدن آیتم مرور به عنوان انجام‌شده
```

---

## پرامپت ۶: تدریس، آزمون، آمادگی و داشبورد

```
صفحات باقی‌مانده را کامل کن:

1. تدریس و عقب‌ماندگی:
   - لیست مباحث + وضعیت تدریس
   - تعریف هدف تست
   - نمایش پیشرفت و عقب‌ماندگی

2. مرکز آزمون:
   - لیست آزمون‌ها
   - ایجاد آزمون
   - شروع اجرا و ورود پاسخ‌ها
   - مشاهده نتیجه

3. آمادگی آزمون:
   - انتخاب مباحث آزمون آینده
   - نمایش برآورد درصد
   - لیست کارهای پیشنهادی

4. داشبورد اصلی:
   - کارت‌های خلاصه آماری
   - درصد کلی و به تفکیک
   - آخرین فعالیت‌ها
   - میانبرهای مهم
```

---

## پرامپت ۷: نهایی‌سازی Frontend

```
1. تمام حالت‌های لودینگ، خطا و خالی بودن داده را مدیریت کن.
2. پیام‌های خطا را فارسی و قابل فهم نشان بده.
3. طراحی ریسپانسیو باشد (حداقل برای دسکتاپ و تبلت).
4. README.md کامل Frontend را بنویس.
5. مطمئن شو با دستورات زیر اجرا می‌شود:
   - npm install
   - npm run dev
و به Backend روی پورت 8000 وصل می‌شود.
```
