# تکنولوژی‌های نسخه ۰.۲

انتخاب تکنولوژی‌ها با در نظر گرفتن این موارد انجام شده است:

- شما برنامه‌نویسی کمی بلدید → باید ساده و قابل فهم باشد
- پروژه توسط هوش مصنوعی ساخته می‌شود → تکنولوژی‌های محبوب و با مستندات قوی
- وب‌اپ باشد و روی ویندوز (و هر سیستم‌عامل دیگر) اجرا شود
- قابلیت توسعه در نسخه‌های بعدی را داشته باشد

---

## پشته پیشنهادی اصلی (توصیه‌شده)

| لایه | تکنولوژی | دلیل انتخاب |
|------|----------|-------------|
| فریمورک اصلی | **Next.js 15 (App Router)** | هم Frontend و هم Backend در یک پروژه |
| زبان | **TypeScript** | کاهش خطا و کمک به AI برای تولید کد تمیز |
| استایل | **Tailwind CSS** | سریع و مناسب RTL |
| کامپوننت UI | **shadcn/ui** | زیبا، قابل سفارشی‌سازی و مدرن |
| ORM | **Prisma** | ساده، قدرتمند و مناسب مدل داده رابطه‌ای |
| دیتابیس | **PostgreSQL** (یا SQLite برای شروع محلی) | مناسب تاریخچه و روابط پیچیده |
| احراز هویت | **NextAuth.js (Auth.js)** | استاندارد و ساده برای Credentials |
| اعتبارسنجی | **Zod** | اعتبارسنجی قوی فرم‌ها و API |
| آیکون | **Lucide React** | سبک و زیبا |

## نکات مهم برای تولید با AI

1. همیشه از **TypeScript** استفاده شود.
2. تمام متن‌های رابط کاربری **فارسی** و **RTL** باشند.
3. از `dir="rtl"` در layout اصلی استفاده شود.
4. تمام تاریخ‌ها با تقویم شمسی نمایش داده شوند (در نسخه‌های بعدی می‌توان کامل‌تر کرد).
5. Prisma Schema باید دقیقاً مطابق سند مدل داده نوشته شود.
