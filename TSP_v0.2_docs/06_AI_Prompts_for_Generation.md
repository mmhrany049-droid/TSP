# پرامپت‌های آماده برای تولید TSP v0.2 با هوش مصنوعی

این پرامپت‌ها را **به ترتیب** و **جداگانه** به هوش مصنوعی بدهید.

قبل از هر پرامپت، این جمله را اضافه کنید:

> «تو یک توسعه‌دهنده ارشد Full-stack با تجربه بالا در Next.js، TypeScript، Prisma و طراحی سیستم‌های آموزشی هستی. کد تمیز، خوانا، تایپ‌شده و مطابق بهترین شیوه‌ها بنویس. تمام رابط کاربری باید فارسی و RTL باشد.»

---

## پرامپت ۱: راه‌اندازی پروژه و Schema

```
یک پروژه Next.js 15 با App Router + TypeScript + Tailwind CSS + Prisma بساز.

نام پروژه: TSP
هدف: سامانه مدیریت تست، مطالعه و آمادگی آزمون برای دانش‌آموز رشته ریاضی-فیزیک

ساختار پوشه‌ها را استاندارد و تمیز بساز.

فایل prisma/schema.prisma را دقیقاً بر اساس مدل داده زیر بنویس:

- User
- Book
- BookNode (با parentId و nodeType)
- Topic
- Question (با displayNumber، correctAnswer، isImportant، isHard)
- QuestionTopic
- QuestionAttempt
- PreviousSolvedEntry
- TeachingRecord
- TeachingGoal
- Exam
- ExamTopic
- ExamQuestion
- ExamAttempt
- ExamAnswer
- FutureExamPlan
- ReviewItem

روابط را درست تعریف کن و از onDelete مناسب استفاده کن.
فقط ساختار پروژه + schema + تنظیمات اولیه را بساز. صفحات را هنوز کامل ننویس.
```

---

## پرامپت ۲: احراز هویت و Layout اصلی

```
ادامه پروژه TSP را بنویس.

۱. سیستم Authentication کامل با NextAuth.js (Credentials Provider) پیاده‌سازی کن.
۲. صفحات Login و Register را با طراحی تمیز، مدرن و کاملاً فارسی + RTL بساز.
۳. Layout اصلی داشبورد را بساز که شامل:
   - سایدبار راست (چون RTL است) با منوهای: داشبورد، کتاب‌ها، تست‌ها، مرور، تدریس، آزمون‌ها
   - هدر با نام کاربر و دکمه خروج
۴. Middleware برای محافظت از مسیرهای خصوصی اضافه کن.
۵. از shadcn/ui یا کامپوننت‌های تمیز Tailwind استفاده کن.

کد باید TypeScript کامل باشد.
```

## پرامپت ۳: ماژول کتاب و ساختار (LibraryManager + QuestionBank)

```
ماژول مدیریت کتاب و بانک تست را برای TSP پیاده‌سازی کن.

قابلیت‌های لازم:
- ایجاد کتاب جدید (عنوان، درس، ناشر، پایه)
- تعریف ساختار کتاب با BookNode (فصل و بخش)
- اضافه کردن تست به بخش مورد نظر
- هر تست باید:
  - شناسه داخلی یکتا داشته باشد
  - شماره نمایشی داشته باشد
  - پاسخ صحیح داشته باشد
  - امکان علامت مهم و سخت داشته باشد

API Routes لازم را بساز و صفحات Frontend مربوطه را هم با UI تمیز و فارسی پیاده‌سازی کن.

صفحات مورد نیاز:
- لیست کتاب‌ها
- جزئیات کتاب + ساختار درختی
- فرم اضافه کردن تست
```

## پرامپت ۴: ثبت تلاش و مرور (AttemptTracker + SmartReview)

```
ماژول ثبت تلاش تست و مرور هوشمند را پیاده‌سازی کن.

قواعد بسیار مهم:
- هر بار حل تست یک رکورد جدید در QuestionAttempt ایجاد شود
- هیچ‌وقت رکورد قبلی overwrite نشود
- نتیجه می‌تواند correct | wrong | unanswered باشد
- زمان صرف‌شده اختیاری است
- امکان ورود تست‌های «قبلاً حل‌شده» وجود داشته باشد (PreviousSolvedEntry)

قابلیت‌های مرور:
- فیلتر غلط‌ها
- فیلتر نزده‌ها
- فیلتر مهم
- فیلتر سخت
- امکان ترکیب فیلترها

صفحه حل تست (ورود پاسخ) و صفحه مرور را با UX خوب بساز.
```

## پرامپت ۵: تدریس، داشبورد و Topic

```
ماژول‌های زیر را پیاده‌سازی کن:

۱. TopicTree: تعریف مباحث آموزشی و اتصال تست به مبحث
۲. TeachingProgress: ثبت تدریس‌شده + تعریف هدف تعداد تست + نمایش عقب‌ماندگی
۳. AnalyticsDashboard: 
   - درصد کلی
   - درصد به تفکیک مبحث
   - تعداد غلط / نزده / مهم / سخت
   - وضعیت عقب‌ماندگی
   - آخرین تلاش‌ها

داشبورد باید خلاصه و کاربردی باشد.
```
