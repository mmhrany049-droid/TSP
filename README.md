# TSP

TSP یک سامانه شخصی برای مدیریت تست، مطالعه و آمادگی آزمون رشته ریاضی-فیزیک است.  
تی‌اس‌پی شماره تست و پاسخ صحیح را نگه می‌دارد، هر بار حل را جدا ثبت می‌کند و درصد را از روی همان سابقه حساب می‌کند. متن سؤال ذخیره نمی‌شود.

نسخه قابل اجرای این مخزن، **فاز اول** است و این سناریو را از مرورگر پوشش می‌دهد:

ثبت‌نام → ورود → ساخت کتاب → افزودن فصل → افزودن تست → حل تست → دیدن نتیجه و درصد

اسناد کامل محصول در [`TSP_v0.3_docs`](TSP_v0.3_docs) است. مباحث، مرور، تدریس، آزمون و آمادگی برای فازهای بعد همان اسناد مانده‌اند.

## اجرا

دو سرویس جدا هستند و فقط با REST API حرف می‌زنند.

1. بک‌اند روی پورت 8000: راهنمای [`backend/README.md`](backend/README.md)
2. فرانت‌اند روی پورت 3000: راهنمای [`frontend/README.md`](frontend/README.md)

```text
frontend (Next.js :3000)  --HTTP/JSON + JWT-->  backend (FastAPI :8000)  -->  SQLite
```

## این فاز

| بخش | فناوری |
|---|---|
| Backend | Python، FastAPI، SQLAlchemy 2، SQLite، JWT |
| Frontend | Next.js 15، TypeScript، Tailwind، رابط فارسی RTL |

مدل‌ها: `User`، `Book`، `BookNode`، `Question`، `QuestionAttempt`.

قواعد ثابت: شماره نمایشی یکتا نیست، هر تلاش یک رکورد جدید است، متن سؤال ذخیره نمی‌شود.
